# CondoFit
Projeto final ENG de Software

## Sobre o Projeto

O **CondoFit** é um sistema de agendamento voltado para moradores e gestores de condomínios que utilizam a academia compartilhada.
Ele resolve o problema de conflitos de horário, superlotação e falta de horários claros, optando por reservas digitais e bloqueios de manutenção.
Fora do escopo desta versão: Controle de entrada, cobrança financeira ou taxas, agendamento de personal trainers e gestão de outras áreas comuns.
