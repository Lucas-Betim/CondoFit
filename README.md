# CondoFit
Projeto final ENG de Software

## Sobre o Projeto

O **CondoFit** é um sistema de agendamento voltado para moradores e administradores de condomínios que utilizam a academia compartilhada do local.
Ele resolve o problema de conflitos de horário, superlotação e falta de transparência na disponibilidade, optando por reservas digitais e bloqueios de manutenção.
Fora do escopo desta versão: controle físico de catracas/biometria, cobrança financeira ou taxas, agendamento de personal trainers e gestão de outras áreas comuns.
