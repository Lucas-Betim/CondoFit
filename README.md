# CondoFit
Projeto final ENG de Software

## Sobre o Projeto

O **CondoFit** é um sistema de agendamento voltado para moradores e administradores de condomínios residenciais que utilizam a academia compartilhada do prédio.
Ele resolve o problema de conflitos de horário, superlotação e falta de transparência na disponibilidade, substituindo planilhas manuais ou cadernos de portaria por reservas digitais organizadas e bloqueios de manutenção.
Ficam fora do escopo desta versão: controle físico de catracas/biometria, cobrança financeira ou taxas de aluguel, agendamento de personal trainers e gestão de outras áreas comuns (como salão de festas ou churrasqueira).
